## Game Overview

**No One Would Even Know** is a first-person  horror game where the main character wakes up in an unknown locked room with no memory of how he got there.

The player must explore the environment, collect clues, and find a way out. As the game progresses, the character discovers diary pages that slowly reveal his forgotten past, the truth behind the strange place he is trapped in.

The game focuses on mystery, fear, memory, and emotional storytelling.
